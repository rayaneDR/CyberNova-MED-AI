# CyberNova films

Editable Remotion source. `npm install`, then `npm run studio` opens the production at port 3100. `npm run render:short` renders the 29-second composition; `npm run render:film` renders the 600-second chapter assembly. Each composition is 30 fps, 1920×1080 before scaling.

## Delivered short

`exports/CyberNova-MED-AI-NASA-Official-Demo-29s-narrated.mp4`: actual Remotion video with locally synthesized English narration. Verified H.264/AAC, 1920×1080, 30 fps and 29.000 seconds. The narration was synthesized using Windows System.Speech and is acknowledged in MP4 metadata. On-screen captions explain the scenes; the SRT is also supplied. No music track was added. Original generated imagery is visibly labeled. The real dashboard recording shows the public synthetic Demo site, including its actual loading states.
